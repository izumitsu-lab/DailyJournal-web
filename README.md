# Daily Journal テスト

実際のブラウザ（Chromium）でアプリを開き、偽の Supabase サーバーに複数の「端末」をつないで確認します。
本物の Supabase には接続しません。

## 実行方法

```bash
cd tests
npm install
npx playwright install chromium   # 初回のみ
npm test
```

## 内容

- `test-sync.js` … 同期（オフライン編集・削除の伝播・競合・新端末・スキーマ未更新時の停止・画像）
- `test-ui.js` … XSS対策、PCサイドバーの再表示、スマホ用CSS、旧形式データの移行
- `test-round2.js` … 空ノートのキャンセル、月表示、Ctrl/Cmd判定、タイプ復活、バックアップ書き出し、
  カードビューの描画削減、ノート編集中の競合
- `test-round3.js` … クラウドの不要画像の掃除（使用中・猶予期間中は残す、他端末の再アップロード、画像欠損時も同期継続）、
  複数タブ（後から開いたタブだけが保存し、前のタブは上書きしない）
- `test-settings.js` … 設定（タイプ・カテゴリ）の同期：古い設定の端末が編集しても他端末の追加が消えない、
  オフライン中の両端末の変更、削除・並べ替え・所属タイプ変更のマージ、端末の時計のずれ
- `test-settings-initial.js` … 以前のバージョンから使っている端末（設定に編集時刻の記録がない）の
  タイプ・カテゴリが、新しくログインした端末に届く／クラウドの既定値で上書きされない
- `test-stability.js` … iPhone での安定性（ビューの連打で描き直しは最後の1回、一覧は縮小画像、画面外の画像を手放す）、
  「軽量化」ボタンは画像が直接入った行があるときだけ表示・同期で自動的に置き換わる
- `test-photo-quality.js` … 写真の保存サイズ（高画質・標準・節約・最小）が設定どおりに縮小され、保存済みの写真は変わらない。
  投稿画面での画質の選択（写真を選んだ後に変えても作り直す・大きさの表示・開き直すと既定に戻る）
- `test-bulk-shrink.js` … 過去の写真をまとめて縮小（期間・大きさの指定、件数と空く容量の見込み、重複写真の共有、同期、クラウド・端末の古い画像の削除）
- `test-backdate.js` … 後日記入（過去の日への書き足し、既存の記録の日時の変更、外せない印、実際の記入日時、日付の移動が他の端末で重複しない、カレンダー・写真ビューの表示）
- `test-pin.js` … しおり（付け外し、生成りのカード、同期、しおり一覧・絞り込み・画面の行き来、写真ビュー、後日記入との併用）
- `test-ios.js` … iPhone 対策（閉じた画面はぼかしの層を作らないよう完全に隠す・タッチ端末はぼかしを弱める、ログイン後にパスワードを入力欄に残さない、版の表示と ?v= の一致）
- `test-popups.js` … スマホのカレンダー・リンクのポップアップ（浮いたカード、月の移動、表示の切り替え、日付・今日・検索、リンクの一覧・解除・追加・空の表示）
- `test-bar.js` … 下のメニューのラベル（日表示・週表示・月表示など）が 390px・320px 幅のどの表示でも途切れない、長いラベルは縮めて収める
- `test-focus.js` … PC の集中モード（左右のサイドバーを隠して中央に、Esc で戻る、前の開け閉めに戻る）、同期に問題があるときだけ設定アイコンに点
- `test-layout.js` … ノートのタイトルが横幅いっぱいを使う（ボタンと重ならない）、追記・編集画面の見出しが 390px・320px で1行に収まる
- `bench-memory.js` … 画像の多いデータで、展開された画像のメモリ量と描画回数を測る（`node bench-memory.js`）
- `harness.js` / `fake-supabase.js` … テスト用の偽サーバー（timestamptz は Postgres と同じ形式で返す）
