🛠️ データベースセットアップ (初回のみ)
セキュリティ（RLS）のため、Supabaseの「SQL Editor」に以下を貼り付けて実行し、テーブルを作成してください。
⚠️ 以前このアプリを設定済みの方へ：同期方式を更新しました（削除の同期・記録単位のマージ・サーバー時刻）。既存の環境でも下記SQLをもう一度すべて実行してください。実行するまでクラウド同期は一時停止し、入力は本体にのみ保存されます（データは失われません）。
⚠️ images バケットは必ず非公開（public = false）のままにしてください。既に public = true で作成・変更してしまった場合は、下記の UPDATE 文を実行して非公開に戻してください。
UPDATE storage.buckets SET public = false WHERE id = 'images';
🧹 データベース軽量化（画像の再アップロード）
以前の設定ミス等で、画像がStorageではなくデータベース側に直接入ってしまっている場合に使います。本体（このスマホ/PC）に保存されている元データを元に、画像をクラウドStorageへアップロードし直し、データベース側は参照だけの軽い状態にします。
※クラウドに画像が直接残っている行が見つかったときだけ表示されます。通常は同期のたびに自動で置き換わるので、表示が消えない場合にだけ使ってください。
🧽 クラウドの不要な画像を削除
記録やノートを削除しても、クラウド（Storage）上の画像ファイルは残ります。どの記録・ノートからも使われていない画像を探して削除し、容量を空けます。直近7日以内にアップロードされた画像は対象外です。端末内の画像には影響しません。
